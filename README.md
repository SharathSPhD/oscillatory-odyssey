# Oscillatory Odyssey

An interactive exploration of oscillatory systems and vibrations through physics-based simulations.

## Overview

Oscillatory Odyssey is a comprehensive educational resource for understanding oscillatory systems, vibrations, and wave phenomena using interactive simulations and visualizations. This project uses Python for simulation and Jupyter Book for presentation.

## Features

- **Interactive Visualizations**: Dynamic plots and animations for exploring oscillatory systems
- **Physics-Based Simulations**: Accurate models of various oscillatory phenomena
- **Educational Content**: Clear explanations of fundamental concepts
- **Interactive Exercises**: Practice problems with immediate feedback

## Getting Started

### Online Access

Visit our published Jupyter Book at [https://SharathSPhD.github.io/oscillatory-odyssey](https://SharathSPhD.github.io/oscillatory-odyssey) to interact with the simulations directly in your browser.

### Local Installation

To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/SharathSPhD/oscillatory-odyssey.git
   cd oscillatory-odyssey
   ```

2. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Launch Jupyter Lab:
   ```bash
   jupyter lab
   ```

## Contents

- **Simple Harmonic Motion**: Explore spring-mass systems, pendulums, and other SHM examples
- **Damped Oscillations**: Investigate the effects of damping on oscillatory systems
- **Forced Oscillations**: Study resonance and frequency response
- **Coupled Oscillators**: Analyze the behavior of interconnected oscillatory systems
- **Wave Propagation**: Visualize wave motion in various media
