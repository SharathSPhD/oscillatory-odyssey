# Oscillatory Odyssey

An interactive Jupyter Book exploring oscillations, vibrations, and related physics concepts.

## Interactive Features

This book uses Thebe to provide interactive code cells. Click the "Live Code" button at the top of any page to make the code cells interactive.

## Requirements

The interactive features require a Binder environment with the dependencies listed in requirements.txt.

## Local Development

If you want to run this book locally, set up a Python environment with the dependencies listed in requirements.txt.
