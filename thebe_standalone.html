Minimal Thebe Demo

This is a minimal example showing Thebe working with a simple Python code cell.

Click the button to start Thebe

Simple Python Example

import numpy as np
import matplotlib.pyplot as plt

# Generate some data
x = np.linspace(0, 10, 100)
y = np.sin(x)

# Create a simple plot
plt.figure(figsize=(8, 4))
plt.plot(x, y)
plt.title('Simple Sine Wave')
plt.xlabel('x')
plt.ylabel('sin(x)')
plt.grid(True)
plt.show()

Instructions

  1. Make sure you're accessing this page through a web server (http://localhost:8000)
  2. Click the "Activate Thebe" button above
  3. Wait for the connection to be established (may take a minute)
  4. Once ready, you'll see a "Run" button appear in the code cell
  5. Click "Run" to execute the code and see the plot

If This Works But Your Book Doesn't

If this minimal example works but your Jupyter Book still has issues:

  1. The problem is likely related to specific packages your notebooks need
  2. Create a custom Binder repository with all required packages
  3. Update the Thebe configuration to use your custom repository

Note: First-time connections to Binder may take several minutes to build the environment.
