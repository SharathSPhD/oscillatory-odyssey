Thebe Cell Detection Test

This page tests various cell formats to see which ones Thebe detects:

1. Standard pre tag:

import numpy as np
print("Hello from a standard pre tag")

2. Highlight-python div with pre:

import matplotlib.pyplot as plt
plt.plot([1, 2, 3, 4])
plt.show()

3. Pre with python class:

def greet(name):
    return f"Hello, {name}!"
    
print(greet("World"))

4. Cell div format:

import pandas as pd
df = pd.DataFrame({'A': [1, 2, 3], 'B': [4, 5, 6]})
print(df)
            
   A  B
0  1  4
1  2  5
2  3  6

Troubleshooting

  • Open browser devtools (F12) to see which cells are detected
  • Look for elements with the class 'thebelab-cell' after loading
  • Check console for any errors during initialization
